# Boards Module UX

## Purpose
Allow users to build custom dashboards using panels and groups.

## Layout
- Header: board tabs and add or duplicate view actions.
- Canvas: grid layout with draggable and resizable panels.

## Primary Interactions
- Add panel wizard with panel type selection.
- Panels support drag, resize, and quick refresh.
- Panel menu includes edit, duplicate, and remove.

## Panel Types
- Resource list
- Resource detail
- Node or pod metrics
- Web URL
- Terminal
- Topology tree

## Empty State
- No boards: show "Create your first board" with a primary action.

## Success Criteria
- Users can build a basic board in under 5 minutes.
